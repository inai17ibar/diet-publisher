# 本人向け健康週報（準備）

diet-mcpの feat/apple-health-import ブランチのAPIを利用する。
先に受信APIをデプロイし、iPhoneから同期・実測照合を完了する必要がある。

既存のDIET_MCP_URL / DIET_MCP_API_KEY設定を使用し、リポジトリ直下で:

```sh
python -m scripts.health_week_report --date 2026-11-13
```

JST月〜日の歩数・活動エネルギー・体重の日別値、記録日数と週平均、食事記録日平均を
標準出力に表示する。本人の端末で実行し、出力を公開CIログに流さない。
取込用トークンではこのAPIを読めない。

この段階ではSNS画像・自動投稿・採点には接続しない。活動エネルギーを総消費量として
扱わず、カロリー目標や減量予測の自動変更も行わない。
前週比較やグラフ、本人用認証付きUIは次段階。
